## 0.85

- **河格点击的轻微卡顿修了（你的猜想对了）**：河格一格里既有河道（水面 -0.3）又有两岸堤岸（≈ 0），整格高度不平（实测 -0.3 ~ -0.014），0.84 的「整格平就用常数」对河格不成立，光圈采 ~441 个点仍然逐点调 `water.surfaceAt`（河格里一次约 3.4ms，≈ 1.5 秒）。现在每个水格（海 / 河）第一次被点到时**只采一次 5×5 网格**（偏移 ±0.9 / ±0.45 / 0，共 25 点；先采其中 9 点判平整，平的海格不用采剩下的 16 点），缓存，光圈上任意点用双线性插值。实测河格：首次 85ms（原来 ~1.5 秒），之后 1.9ms；与精确值最大误差 0.114（只在堤岸陡坡处，光圈是装饰，够用）。光圈**确实要计算高度**（贴着地形才不会悬空 / 沉进地里），只是不用每个点都去查。试过「进场景后逐格预热」，每格在主线程占 ~85ms 会拖慢开局几秒的动画，已去掉，只留点到时现算
- **沼泽掉血飘字改成红色**：新增 `.dmg.hurt`（红字深红描边），沼泽用它；被攻击的伤害飘字仍是默认的金黄色，回血是绿色
- **移动提速约 1.5 倍**：`world.js` 的 `SPEED`（单位 / 秒）步兵 3.0 → 4.5，轻型 5.0 → 7.5，中型 4.4 → 6.6，重型 3.6 → 5.4，火炮 3.8 → 5.7，机械同比例。步兵的跑步动画按脚步节奏自动加快（上限 3 倍播放速率）；移动力（点数）不变，只是走得更快
- **第一关不再要求地形左右完全镜像**（`levels/level1.js`）：山 / 沙漠 / 沼泽 / 树林由东西两半**各自独立**生成（东半边在「镜像坐标」里用同一套规则再随机一遍，最后翻到东边，每片的连通性检查把两半一起算）；「两池」和「贴边海湾」东西两个各自独立（形状 / 大小 / 上缘还是下缘都可以不同）。**仍然镜像**的：基地、城市、公路、河、起始部队、中央的矩形湖 / 不规则湖（它们本来就跨中线）——这是公平和「公路必须通」的底线。为了让独立生成的东西不压到镜像的东西，`west()` 现在要求「这格和它的镜像格都是陆地」，沙漠 / 沼泽的「周围一圈都得是草」也两侧都查。300 个种子全部生成成功，299 个的山不再左右对称。同一个 seed 的地图和 0.84 又不同了

## 0.84

- **沼泽掉血时机改了**：以前是自己结束回合时扣；现在**自己结束回合不扣，等对方也结束、又轮回到自己的回合开始时才扣**（和收入、修理在同一个「回合开始」阶段，动画仍与修理同一刻）。`endTurn` 里沼泽结算从「换人前」挪到「换人 + 收入 + 修理后」，作用对象是轮到的这一方；沼泽把这一方扣光 = 对方获胜。`CONFIG.swampDamage` 的注释与地形说明同步更新；规则测试改写（先蓝军结束一次不扣，红军再结束、轮回蓝军才扣；致死 / 只剩 5 点 / 不致死留 1 点 都改成「第二次 endTurn」）
- **修了 0.83 的「点单位卡几秒」**：0.83 的海岸站位对每个浅滩 / 断崖格在格内铺 19×19 个采样点，而 `water.surfaceAt` 在水面上一次要约 5ms（陆地才 0.5ms），所以第一次点到海岸附近的单位（要算移动范围里每个海岸格的站位）会卡好几秒，只有「范围里有海岸格且是第一次」才卡，所以「有时有、有时没有」。现在：① 站位改成「按离格心由近到远逐点试、第一个合格的就停」，只采几个点并缓存；② 全部海岸格在**建场景时一次算好**（第一关 18 个格约 60ms），点击时只查缓存
- **修了「点海水卡顿」（一直都有的 bug，根因找到了）**：点格子的黄框光圈要对约 441 个点逐个调 `world.surfaceY`，海 / 河格每次落到 `water.surfaceAt`（水里一次约 5ms），点一下海水 ≈ 2 秒（无头浏览器实测）。海面其实是**平的**（实测整格恒为 -0.3），不是起伏的波面——你的猜想「波折面」不是原因，原因是「水里取高度这个查询本身很贵」。现在 `surfaceY` 对海 / 河格先做一次 9 点平整度检测（中心 + 四角 + 四边中点，高差 < 0.004），整格平就直接返回常数：441 点采样从约 2 秒降到 41ms（首次，含检测），之后 0.6ms。河若有起伏则自动走原来的精确查询（本版没找到有起伏的河格）
- **第一关水域和河流更多样**（`levels/level1.js`）：① 新增**贴边海湾**：贴着棋盘上缘或下缘的不规则海湾（深入 1–3 行、5–11 格），镜像后左右各一个，起点靠近中线时在中线连成一个；② 河流改成**会拐弯**：随机走法 = 向下 / 偶尔横着走 1–3 格再向下（两次横走之间必须先向下一格），横向活动范围 x ∈ [-7,-3]，长度 7–11 格，且「河不能自己贴自己」（不相邻的两格至少隔一格）；桥仍架在笔直河段上。③ 水域占比重新分配：矩形湖 30% / 不规则湖 20% / 两池 15% / 贴边海湾 25% / 无湖 10%。300 个种子全部生成成功，边缘海岸、河接缝测试都过；**同一个 seed 的地图和 0.83 不同了**（随机序列变了）。第一关仍是左右镜像，所以「不对称的水」暂时做不了
- 测试：`tools/smoke-swamp.py` 改成红军站沼泽；`smoke-capture.py` 在第 ③ 步前把镜头对准单位（旧测试靠运气，换图后单位在屏幕外）；`smoke-detail.py` 种子 7 → 11（种子 7 的新地图在屏幕左缘有个单位，测试点左缘关面板会误选它）；`check-rules.mjs` 沼泽两项改写
