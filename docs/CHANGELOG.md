## 0.68

- **修：浮条不跟着单位走**。原因：拖动镜头时走的是 `cam.pan` 直接改相机，`cam.update` 不一定报「变化」，而浮条只在「变化」时才重新定位；现在每次出帧后都按单位位置重新贴一次（`barPlace()` 挪到 `renderer.render` 之后）。冒烟测试里新增「拖镜头后浮条仍贴着单位」的断言
- **新：撤销移动**。走完、选「待命」之前，**点浮条以外的空白处 = 撤销**：单位瞬间退回原格，回到选中状态（蓝格重新出现），可以重新选落点；再点空白处才是取消选中。权衡过按钮方案：贴着「待命」容易误点，放远了又够不着，所以没加按钮；浮条下面加了一行小字「点空白处撤销」做提示。**浮条周围 36px 不算空白**（想点「待命」点偏了不会误撤销）
  - 引擎：`move` 记下 `origin`（原位置 + 燃料），新增 `undoMove(g, id)`（只在已移动、未行动时可用，位置 / 燃料 / 已移动一起还原）；`wait` / 回合重置清掉 `origin`；规则测试 +1（18 项）
  - 战场：`world.placeAt(u, cell)` 瞬间放回；`main.js` 的 `undoMove()` / `nearBar()`；`handleTap` 在 `acting` 时改成「浮条外 = 撤销」
- **新：蓝格呼吸动画**（GBA 高战 2 的味道）：整片蓝格透明度在 .24–.46 之间慢慢明暗（周期约 1.2 秒），颜色调得更蓝一点（`0x72c6ff`），底下地形一直看得清。有蓝格时按约 30 帧/秒出帧（同光圈，不计入帧率小标）。【暂定】速度 / 深浅 / 颜色在 `world.js` 的 `pulseRange`，想换成「高战复刻版」那种更慢更柔的，改一个系数就行
- 视锥剔除：确认一直开着（单位级 `world.cull` + 网格级 `frustumCulled`），本版未改
- 新增 / 改 `tools/smoke-move.py`（蓝格呼吸、拖镜头浮条跟随、撤销后重走；拖动用页内一次性派发事件，避免无头浏览器每帧很慢时被当成长按）
