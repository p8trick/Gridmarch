# 更新日志（0.91 起）

> 0.90 及以前的日志在 `docs/archive/CHANGELOG_至0.90.md`（不用读）。每个新版本在下面最上方插一条，5–8 行：做了什么 / 为什么 / 改了哪些文件。

## 0.91 · 胜利结算面板 + 统计表
- 规则引擎新增**统计表** `g.stats[玩家]`：`built` 生产数 · `lost` 损失数（含沼泽致死）· `killed` 击毁数（含反击击毁）· `captured` 占领数 · `income` 累计收入 · `spent` 累计军费（造兵 + 修理）；另有 `g.winReason`（`hq` / `wipe` / `draw`）、`g.winCell`（占领的总部格）。`forecast` 复制统计表，预估不污染真数据。
- 新增 `summaryOf(g)`：每方 + 现存单位 / 据点数 / 各类据点数，中立据点数及分类——胜利面板和下一步的战场情报共用。
- 新增 `src/battle/result.js`：**胜利结算面板（方案 A 双盒战报）**。左盒 = 胜利牌（盖章「胜利」+ 队伍 + 第 N 天 + 怎么赢的 + 再来一局 / 回主页 / 看战场）；右盒 = 蓝红对照表（已生产 / 损失 / 击毁 / 据点 / 累计收入 / 累计军费，条形比数量，占优一方数字放大）。
- 加了方案 C 的表现：胜负分出时**败方全部压灰**、镜头平移到被占的总部并**缓慢绕场**（碰一下战场或点旋转就停）；「看战场」把面板收成底部细横幅（胜方 · 第 N 天 · 击毁 / 损失 / 据点），点横幅再展开。「再来一局」= 同一张图重开。胜负已分后点左上状态条不再弹结束回合确认。
- 改动文件：`src/rules/engine.js` `src/battle/{result.js,main.js,battle.css}` `tools/{check-rules.mjs,smoke-result.py}` `index.html`（版本号）。测试：规则 35 项（+2）、新增 `smoke-result`。
